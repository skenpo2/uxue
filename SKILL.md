# UXUE Website Design & Engineering Skill

## Purpose

You are responsible for rebuilding the UXUE corporate website into a premium enterprise technology website.

The primary visual and UX reference is:

https://www.cbcemea.com/

The objective is NOT to copy CBC EMEA.

The objective is to reproduce the same level of:

- Design quality
- Visual restraint
- Editorial composition
- Typography
- Spacing
- Navigation clarity
- Information architecture
- Content hierarchy
- Enterprise credibility
- Conversion experience

while using UXUE's own:

- Logo
- Brand identity
- Orange accent
- Photos
- Project images
- Services
- Industries
- Company information
- Technology partners
- Existing factual content

The finished website must look like a premium UXUE website that belongs in the same class of enterprise technology websites as CBC EMEA.

---

# 1. DESIGN PHILOSOPHY

The website must feel:

- Established
- Premium
- Corporate
- Editorial
- Technical
- Confident
- Restrained
- Intelligent
- Trustworthy
- Human
- Enterprise-focused

Avoid:

- Generic SaaS design
- Generic AI website aesthetics
- Excessive gradients
- Neon colors
- Cyberpunk aesthetics
- Excessive glassmorphism
- Excessive rounded cards
- Floating random UI elements
- Overly decorative illustrations
- Template-like card grids
- Excessive shadows
- Excessive animation
- Cheap stock photography
- Artificial-looking AI imagery

The website should look designed, not generated.

# 3. COLOR SYSTEM

UXUE's existing brand remains the primary brand identity.

The website should adopt the visual restraint of CBC EMEA.

Use:

- Off-white / warm neutral backgrounds
- Deep charcoal / near-black text
- Muted neutral surfaces
- Subtle borders
- UXUE orange as the primary accent

Orange should be used intentionally.

Good uses:

- CTA buttons
- Active navigation states
- Small highlights
- Eyebrows
- Links
- Hover states
- Small visual accents
- Important numbers
- Section markers

Do NOT make the entire website orange.

Orange should feel like an accent rather than the dominant background.

Avoid:

- Orange gradients
- Orange everywhere
- Neon orange
- Multiple competing accent colors

The goal is:

CBC-style restraint + UXUE orange identity.

---

# 4. TYPOGRAPHY

Typography is one of the highest-priority parts of the redesign.

Use the existing UXUE font if appropriate.

If the existing font does not produce the desired visual quality, select a premium modern sans-serif with an editorial enterprise character.

Typography must have:

- Strong hierarchy
- Large but controlled headlines
- Generous line-height
- Controlled paragraph width
- Consistent weights
- Deliberate letter spacing

Use section labels such as:

SOLUTIONS

INDUSTRIES

PROJECTS

INSIGHTS

ABOUT

These should be visually distinct from normal body copy.

Large headings should feel editorial rather than like marketing-template headlines.

Avoid excessive boldness.

---

# 5. LAYOUT

Use an editorial grid.

Do NOT build every section as a grid of cards.

Use:

- Large text blocks
- Split layouts
- Full-width imagery
- Editorial columns
- Asymmetric compositions
- Horizontal rows
- Numbered sections
- Structured lists
- Large whitespace
- Thin dividers
- Image/text relationships

Cards should only be used when they genuinely improve information hierarchy.

The site should breathe.

---

# 6. CONTAINER

Create one consistent global container system.

Example:

Desktop:
max-width approximately 1280–1440px

Large horizontal margins.

Tablet:
fluid container.

Mobile:
comfortable side padding.

Do not allow every component to choose its own arbitrary width.

The website should have a visible underlying grid.

# 9. IMAGE PHILOSOPHY

UXUE's existing photography is a major asset.

Use it.

Before introducing new imagery:

1. Search the existing repository.
2. Identify all existing images.
3. Identify project photos.
4. Identify team photos.
5. Identify infrastructure photos.
6. Identify product/technology photos.
7. Identify logos.
8. Identify partner logos.

Reuse the best existing imagery throughout the redesign.

Do not unnecessarily replace real UXUE work with stock images.

Images should be presented editorially.

Use:

- Large photography
- Cropped photography
- Full-width photography
- Image + text layouts
- Project galleries
- Subtle image hover effects

Avoid:

- Tiny images inside generic cards
- Excessive image overlays
- Cheap gradients over photos

# 30. GOLDEN RULE

Do not ask:

"How can I make this page prettier?"

"How would a premium enterprise technology company communicate this information?"

Confident.

Editorial.

Technical.

Premium.

Human.

Enterprise.

The website should feel expensive because of its **composition and restraint**, not because it contains lots of visual effects.
